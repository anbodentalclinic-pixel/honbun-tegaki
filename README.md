# 本文 手書き(Program 6・7)

教科書本文を、単語 → しくみ(文法)→ 音読 → 英→日 → 手で書く、の順に練習するアプリ。本文JUMPの置き換え用。iPhone とプリンターがあれば使える。

- 単語:声で覚える4段階(紹介 → まねる → 頭文字 → ノーヒント。言えたかは自己申告)と、プリントで書く4段階(なぞる → 文字の補充 → 頭文字だけ → 日本語→英語)
- しくみを見つける:文法のルールを動くブロックで見て、問題(えらぶ・ならべる)で確かめる
- キャラクター「ポン」が、正解・まちがいに合わせて動いて声をかける(本文JUMPと同じ)
- 本文音読:お手本を聞いて1文ずつ声に出して読む(声が聞こえれば合格。発音の正誤は判定しない)
- 英→日:英文を聞いて、日本語の意味をえらぶ
- 書く段階:1 語群を見て書く → 2 虫食い(少し) → 3 虫食い(たくさん) → 4 頭文字だけ → 5 何も見ないで書く
- 書き方は3通り(保護者モードで切り替え。最初は「プリントに書く」)
  - プリントに書く:アプリでプリントを作って印刷 → 鉛筆で書く → 1ページずつ撮って、まとめてAI採点(または自分で答え合わせ)
  - ノートに書く:1文ずつノートに書き、撮影または自分で答え合わせ
  - 画面に書く:iPad＋Apple Pencil で画面に書き、自分で答え合わせ
- AI採点:送り先(Cloudflare Worker)のURLは組み込み済み。合言葉は「アドレス#pass=合言葉」のリンクを1回開くか、保護者モードで入力する。合言葉はこのリポジトリに書かない
- まちがえた文は1つ前の段階にもどる。まちがえた単語は次のプリントの虫食いで先に空らんになる
- 保護者モードの「記録しないで中身を見る」:記録を変えずに全部の段階とプリントを確認できる(終わると元の記録にもどる)
- 保護者モード(ホームのボタンを2秒長押し):各種設定、日ごとの取り組み、最近撮ったプリント、文ごとの記録、段階の手動調整
- 記録はブラウザ(localStorage)に保存。プリントは作った端末で採点する
- タイピングでの単語練習は別アプリ「つづりと発音」で行う
