# 本文 手書き(Program 6・7)

教科書本文を、単語 → しくみ(文法)→ 音読 → 英→日 → 手で書く、の順に練習するアプリ。本文JUMPの置き換え用。iPhone とプリンターがあれば使える。

- 単語:声で覚える4段階(紹介 → まねる → 頭文字 → ノーヒント。言えたかは自己申告)と、プリントで書く4段階(なぞる → 文字の補充 → 頭文字だけ → 日本語→英語)
- しくみを見つけるの最初に「まず全体」:代名詞の表(私→あなた→彼…と1行ずつ、その行の例文を1文ずつ音読し、つぎに「〜を・に」の列を強調してその例文を1文ずつ音読。列をかくして確認)、だれが/だれをで形が変わる図(表のどのマスを使っているかを色で表示)。代名詞のレッスンは、そのあとの説明・ルールのまとめ・問題でも、文の代名詞と表のマスを同じ色で対応させて見せる。ほかの3つのレッスンも「文の型の表」を出し、今の文がどの型(行と列)かを色で示す、疑問文ができる過程を1手ずつ動かす図(三単現は「しるし ★ が Do に移って Does、動詞は原形にもどる」と説明。has→have でも確認)、数で is/are が切りかわる図、乗り物で By の答えを作る図
- 単語の「もう一度」:段階に関係なく、復習プリント(全部／まちがえた単語だけ)と、声でもう一度(ノーヒント)が使える
- しくみの説明は文法用語(主格・目的格・be動詞・一般動詞・三単現・原形・疑問詞など)を使い、やさしい言いかえと例文を必ず並べる。用語はタップすると説明が出る
- しくみの「まず全体」の最後に、ルールを「もし〜なら → 〜する」のブロックで見せる画面と、わるい例(バグ)を自分でタップして直し、いい例と見くらべる画面がある
- しくみを見つける:文法のルールを動くブロックで見て、問題(えらぶ・ならべる)で確かめる。出てくる文はすべて声に出して読んでから次へ進む
- キャラクター「ポン」が、正解・まちがいに合わせて動いて声をかける(本文JUMPと同じ)
- 本文音読:お手本を聞いて1文ずつ声に出して読む(声が聞こえれば合格。発音の正誤は判定しない)
- 英→日:英文を聞いて、日本語の意味をえらぶ
- 書く段階はどれも「アプリで練習(聞く → ブロックを入れる → 音読)→ 紙に書く」の順で進む
- 書く段階:1 語群を見て書く → 2 虫食い(少し) → 3 虫食い(たくさん) → 4 頭文字だけ → 5 何も見ないで書く
- 書き方は3通り(保護者モードで切り替え。最初は「プリントに書く」)
  - プリントに書く:アプリでプリントを作って印刷 → 鉛筆で書く → 1ページずつ撮って、まとめてAI採点(または自分で答え合わせ)
  - 印刷:Safari で開いているときは「印刷する」で印刷の画面が出る。ホーム画面のアイコンから開いているときは iPhone が印刷の画面を出せないので、アプリがプリントをPDFにする →「印刷する(PDF)」→ 共有の画面で「プリント」をえらぶ。PDF化には html2canvas 1.4.1(MIT License)を index.html に入れている
  - ノートに書く:1文ずつノートに書き、撮影または自分で答え合わせ
  - 画面に書く:iPad＋Apple Pencil で画面に書き、自分で答え合わせ
- AI採点:送り先(Cloudflare Worker)のURLは組み込み済み。合言葉は「アドレス#pass=合言葉」のリンクを1回開くか、保護者モードで入力する。合言葉はこのリポジトリに書かない
- まちがえた文は1つ前の段階にもどる。まちがえた単語は次のプリントの虫食いで先に空らんになる
- 保護者モードの「記録しないで中身を見る」:記録を変えずに全部の段階とプリントを確認できる。音読や問題を解かなくても先へ進める(終わると元の記録にもどる)
- 保護者モード(ホームのボタンを2秒長押し):各種設定、日ごとの取り組み、最近撮ったプリント、文ごとの記録、段階の手動調整
- 記録はブラウザ(localStorage)に保存。プリントは作った端末で採点する
- 記録の送信:取り組むたびに、記録をスプレッドシート「拓真 英語まちがい記録」(Apps Script)へ自動で送る(アプリ名は「本文 手書き」)。届いたと確認できた分だけ送信ずみにするので、電波がないときの分は次に開いたときにまとめて送る。保護者モードの「日ごとの取り組み」の下で、未送信の件数の確認と「今すぐ送る」ができる。「記録しないで中身を見る」の間は送らない
- タイピングでの単語練習は別アプリ「つづりと発音」で行う
